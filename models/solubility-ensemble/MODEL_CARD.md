# モデルの説明（溶けるか・混ざるか 組み合わせ版 0.2、2026-11-27 の重み）

## 何を返すか

固体の化合物の、25 °C の溶解度の見込み（14 溶媒、2 成分の混合溶媒、原液の希釈）と、誤差の約 7 割が入る幅。実験の前に見当をつけるための物で、実測の代わりではありません。

## 中身

| 部分 | 中身 |
|---|---|
| 有機溶媒 | ① 物理式（理想溶解度と Abraham の式を合わせた物）の残差を学ぶ木と、② 溶質・溶媒の積カーネル回帰の平均（融点なしの時は、融解熱を補助学習した木も混ぜる）。そこに ③ 蒸留した全結合のネットワークを 6：4 で混ぜる |
| 蒸留の教師 | 分子グラフのモデルと記述子の全結合。BigSolDB 2.2 の全温度・AqSolDB・融点の表・DSC の融解熱を同時に学習（GPU）。重みに入っているのは、蒸留した小さな全結合だけ |
| 水 | 水だけの木のモデル（BigSolDB の水と AqSolDB）。表にない分子は、指紋の似た分子の誤差で補正 |
| 手元の実測 | 溶媒どうしの誤差の共分散で重みづけして、ほかの溶媒へ移す（3 溶媒まで） |
| 混合溶媒 | 対数線形の内挿＋溶媒の組ごとの補正（MixtureSolDB で当てはめた） |
| 融点 | 入れた値 ＞ BigSolDB の融点 ＞ 融点の公開データ。構造から推算した融点は目安として返すだけで、計算には使わない |

## 学習データの選び方

- BigSolDB 2.2 の 298.15 ± 5 K を、溶質 × 溶媒ごとに平均した値。有機溶媒の値は、溶液 1 L あたりに直して返します。
- **外した物**：酸と塩基の両方を持つ両性の溶質の有機溶媒の行、分子量 500 以上の有機溶媒の行、誤りの疑いのある文献の行（こちらの見込みとのずれと、SC3 の文献どうしの一致の度合いで選んだ）。
- 融点が BigSolDB にない溶質には、融点の公開データ（Bradley、特許から集めた融点の表）の値を使いました。

## 精度（学習に使っていない溶質で測った値。溶質を分けた 5 分割）

誤差の約 7 割が入る幅です。倍率は上下の倍率。

| 場合 | 融点あり | 融点なし |
|---|---|---|
| 有機溶媒（全体） | log 0.46、約 2.9 倍 | log 0.67、約 4.6 倍 |
| 有機溶媒（溶媒ごと） | 約 2.5 倍（ジクロロメタン）〜4.5 倍（DMSO） | 約 3.7 倍（ジオキサン）〜6.1 倍（ジクロロメタン） |
| 水（木のモデル） | 約 3.6 倍 | 約 4.5 倍 |
| 水（似た分子の補正のあと） | 約 3.5 倍 | 約 4.1 倍 |
| 実測 1・2・3 つから換算 | 約 2.3・2.0・1.9 倍 | 約 2.8・2.4・2.2 倍 |
| 融点がどの表にもない分子の有機溶媒 | — | 約 6.0 倍 |
| 混合溶媒の補正の誤差 | 有機どうし約 1.7 倍、水と有機で約 2.1 倍（両端の幅と合わせる） | 同じ |

- 実測から換算した行は、14 溶媒のうち 2 つ以上に実測がある溶質で測った値です（同じ溶質で実測なしの時は、融点あり約 2.8 倍・なし約 4.4 倍）。
- 約 1 割は、幅の 2〜3 倍より大きく外れます（有機溶媒・融点ありで、約 8 倍を超える物が 1 割）。
- 水の幅は AqSolDB を含めて測った値です。BigSolDB の水の実測だけで測ると、約 4〜6 倍に広がります。
- 例の固体 37 種は学習に使った固体なので、見込みが実測の近くに出ます。
- 外した物（両性・分子量 500 以上・誤りの疑い）を学習と評価の両方から除いた分も、数字の改善に入っています。[../solubility](../solubility/) の幅と、そのまま比べないでください。

## 分かっている限界

- 精度を決めているのは、測定の揺れ（2 つの文献の値の差は log で約 0.08 と小さい）ではなく、**学習した溶質の少なさ**（似た溶質がないことが多い）と、溶媒の種類ごとの効き方です。同じデータでモデルの形を変えても、大きくは縮みませんでした。
- 塩・イオン・混合物、重い原子 80 個超の分子は扱いません。結晶多形、水和物、pH による解離、緩衝液の塩の析出は扱いません。
- 25 °C だけです。
- 混合溶媒の 3 成分（原液の溶媒・水・アセトニトリルの希釈）は、2 成分の組の和の近似で、実測と照合していません。

## 学び直し

学び直しの道具は未同梱です。学習の手順は、上の「中身」と「学習データの選び方」のとおりです。手元のデータで学び直す時は [../solubility/train/](../solubility/train/)（木のモデル）を使ってください。

## 推論の確かめ

`tests/check.cjs` は、`js/solubility_ensemble.js` の値を、サイトのページの計算（`tests/reference.json`）と突き合わせます。例の固体は、実測 0〜3 つからの換算・混合・希釈で 10⁻⁹ まで一致し、SMILES から足す分子は小数 2 桁まで一致することを確かめます。
