# 自社のデータの置き場

*English: put your own `methods.csv` and `measurements.csv` here (format: `../OWN_DATA.md`). Everything in this folder except this README is ignored by git, and nothing is uploaded anywhere.*

- ここに `methods.csv` と `measurements.csv` を置いて、`models/hplc-retention/` で `python train/run.py --own train/own_data` を実行します。
- 形は [../OWN_DATA.md](../OWN_DATA.md)、例は [../examples/zhang_dataset10/](../examples/zhang_dataset10/)。
- このフォルダの中身（この README 以外）は `.gitignore` でリポジトリに入りません。道具はデータをどこにも送りません。
